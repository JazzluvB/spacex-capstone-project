# SpaceX Falcon 9 First Stage Landing Prediction Capstone

This end-to-end data science capstone project predicts Falcon 9 first-stage landing success through API and web scraping data collection, SQLite and Pandas exploratory data analysis, interactive Folium mapping and Plotly Dash visualization, and optimized machine learning classification models achieving an 83.33% test accuracy.

## Repository Structure
- `presentacion_final_spacex.pdf` - Final presentation slides for peer review.
- `notebooks/` - Jupyter notebooks covering data collection, wrangling, EDA, SQL, maps, and ML models.
- `apps/` - Plotly Dash interactive application script.
